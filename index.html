Política de Privacidad de ScrimVision

Última actualización: 18 de agosto de 2026

Esta Política de Privacidad explica cómo ScrimVision procesa la información cuando se utiliza nuestra aplicación de Discord.

1. Información que procesamos

Para proporcionar sus funciones, ScrimVision puede procesar información relacionada con los servidores de Discord donde está instalado.

Dependiendo de las funciones utilizadas, esto puede incluir:

  • ID de usuarios de Discord.
  • Nombre de usuario y nombre visible en Discord.
  • ID de servidores, canales y roles necesarios para el funcionamiento.
  • Información relacionada con jugadores y equipos.
  • Resultados y estadísticas de partidas.
  • Información contenida en mensajes que el bot necesita procesar.

2. Uso de la información

La información procesada por ScrimVision se utiliza exclusivamente para proporcionar las funciones del bot.

Estas funciones pueden incluir:

  • Gestión de scrims y partidas competitivas.
  • Registro de jugadores y equipos.
  • Procesamiento de resultados.
  • Cálculo de puntuaciones.
  • Generación de estadísticas y rankings.
  • Identificación de usuarios necesarios para ejecutar comandos.
  • Administración de funciones dentro de servidores de Discord.

3. Contenido de mensajes

Cuando ScrimVision necesita acceder al contenido de determinados mensajes, dicho acceso se utiliza únicamente para procesar información necesaria para las funciones del bot.

El contenido de los mensajes no se utiliza para publicidad ni para crear perfiles publicitarios de los usuarios.

ScrimVision no utiliza el contenido de los mensajes para entrenar modelos de inteligencia artificial o aprendizaje automático.

4. Almacenamiento de datos

ScrimVision procura limitar el almacenamiento de información a los datos necesarios para proporcionar sus funciones.

La información temporal utilizada durante el procesamiento de una solicitud puede mantenerse únicamente durante el tiempo necesario para completar dicha operación.

No almacenamos deliberadamente conversaciones privadas completas ni creamos un historial de todos los mensajes enviados en los servidores.

5. Datos de presencia

Si una función de ScrimVision requiere información de presencia de Discord, esta información se utiliza únicamente para proporcionar la funcionalidad correspondiente.

Los datos de presencia no se utilizan para publicidad, seguimiento externo ni entrenamiento de modelos de inteligencia artificial.

6. Datos de miembros del servidor

ScrimVision puede procesar información básica de los miembros de un servidor cuando sea necesario para identificar jugadores, administrar equipos, ejecutar comandos o proporcionar funciones relacionadas con las partidas.

Esta información se utiliza únicamente para las funciones del bot.

7. Compartición de información

ScrimVision no vende ni alquila información personal de los usuarios.

No compartimos deliberadamente información personal con terceros para fines publicitarios.

La aplicación utiliza Discord como plataforma para proporcionar sus funciones y está sujeta también a las políticas y condiciones aplicables de Discord.

8. Seguridad

Adoptamos medidas razonables para proteger la información procesada por ScrimVision y reducir el riesgo de acceso, modificación o divulgación no autorizada.

Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

9. Retención de información

Conservamos la información únicamente durante el tiempo necesario para proporcionar las funciones correspondientes o cuando sea necesario para mantener el funcionamiento y la seguridad del servicio.

Los datos que ya no sean necesarios podrán eliminarse o dejar de utilizarse.

10. Solicitudes relacionadas con los datos

Los usuarios y administradores de servidores pueden contactar con el equipo responsable de ScrimVision si tienen preguntas relacionadas con la información procesada por el bot.

Las solicitudes pueden estar sujetas a verificaciones razonables para evitar la divulgación de información a personas no autorizadas.

11. Menores

ScrimVision no está diseñado específicamente para recopilar información de menores de edad.

Los administradores de los servidores son responsables de utilizar el bot de acuerdo con las leyes y normas aplicables en sus comunidades.

12. Servicios de terceros

ScrimVision funciona mediante Discord y puede depender de otros servicios técnicos necesarios para su funcionamiento.

El uso de dichos servicios puede estar sujeto a sus propias políticas de privacidad y condiciones.

13. Cambios en esta Política de Privacidad

Podemos actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en ScrimVision, en la forma en que procesamos información o en los requisitos aplicables.

Cuando se realicen cambios, actualizaremos la fecha indicada al principio de esta página.

14. Contacto

Si tienes preguntas sobre esta Política de Privacidad o sobre el tratamiento de información por parte de ScrimVision, puedes contactar con el equipo responsable a través de los canales oficiales del proyecto.

15. Aceptación

Al utilizar ScrimVision, aceptas el procesamiento de información descrito en esta Política de Privacidad, en la medida necesaria para proporcionar las funciones del servicio.
